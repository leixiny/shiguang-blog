# 拾光志 · shiguang-blog

一个「文章发布 + 分类管理 + 评论互动」的全栈博客系统，用于《全栈应用开发》课程练习。

- 前端：React 19 + TypeScript + Vite
- 后端：Express + JWT + SQLite（node:sqlite）
- 主题：数字经济学习笔记（课程笔记 / 项目复盘 / 行业观察 / 工具技巧）

## 运行

```bash
# 后端（端口 3001，同时托管前端构建产物）
cd server && npm install && npm start

# 前端开发模式（端口 5174，代理 /api 到 3001）
cd web && npm install && npm run dev
```

演示账号：`leixiny` / `demo123456`

## 功能

- 注册 / 登录（JWT + bcrypt），路由守卫保护写作页
- 文章发布 / 编辑 / 删除（仅作者本人），Markdown 正文，标签与专栏
- 列表：分页、分类筛选、关键词搜索、「我的文章」视图
- 评论区：登录用户发表 / 删除本人评论
- 卡片：阅读时长估算、浏览量、讨论数；无封面自动生成渐变封面
- 空状态引导、返回顶部
